# Short demo video checklist (2–4 minutes)
1. Show the GitHub repository and explain the folder structure.
2. Show dataset download and the EDA plots you generated.
3. Show your two models and actual metrics JSON.
4. Open MLflow and show both experiment runs.
5. Run `pytest -q` and show the result.
6. Show `/docs`, submit a sample request to `/predict`, and explain the response.
7. Show `docker build` and a running container.
8. Show GitHub Actions result and, if completed, Kubernetes pods/service.
9. Briefly state the limitations and that this is not a medical diagnostic tool.
